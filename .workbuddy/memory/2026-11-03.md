## git push 网络问题：SSH 通道 443→22 切回
- ssh.github.com:443 被重置（Connection reset / timeout），但 TCP 探测发现 github.com:22 与 github.com:443 均可连通。
- 处理：~/.ssh/config 改回 `HostName github.com / Port 22`（此前是 ssh.github.com:443），直连 22 认证成功（Hi onastra），push 成功（87ff74b..3013d19）。
- 教训：GitHub SSH 端口被重置是间歇性的，22/443 会轮流被卡；遇到 push 失败先用 /dev/tcp 探测 github.com:22、github.com:443、ssh.github.com:443 三条路，哪个通用哪个，再改 ~/.ssh/config。

## 修复「删除注册后无法重新注册」致命缺陷（2026-11-04）
- 根因：face_feature 有 (employee_id, provider) 唯一索引；管理员删除=软删除 status=0 行仍在表中；重新注册时 enroll 的 selectOne 过滤 status=1 返回 null → 走 INSERT → 撞唯一索引 → 50001。FC 上已实测复现。
- 修复：新增 selectAny（不过滤 status）供 enroll 使用，存在旧记录走 updateFeature（会把 status 置回 1 复活）；verify 仍用 selectOne 只认有效注册。

- 验证路径：真机连本机（BASE_URL=电脑IP:8080）可立即测试；注册→打卡→围栏→落库全链路本地即真实 arcsoft 活体。
