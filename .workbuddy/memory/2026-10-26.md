**踩过的 5 个真坑（务必记住）**
1. **`spring-security-crypto` 不在 Spring Boot 依赖管理里**！Spring Boot 3.3.5 有 `spring-security.version=6.3.4` 但没纳管这个 artifact，必须在 parent pom 显式锁 `6.3.4`。（只引入 crypto，不引 Spring Security 全家桶，符合"自研 JWT 鉴权"决策。）
2. **BCrypt 摘要格式**：库中是纯 `$2a$10$...` 无 `{bcrypt}` 前缀。`DelegatingPasswordEncoder` 找不到前缀会**抛 IllegalArgumentException 而非返回 false**，登录直接 500。已统一改用 `new BCryptPasswordEncoder()`（AuthService 与 UserService 必须一致，否则同一个库会出现两种摘要格式）。
3. **Element Plus 图标需单独全局注册**：`app.use(ElementPlus)` 只装 UI 组件不含图标集合，菜单用 `<component :is>` 动态渲染会失败。main.js 已加 `for (const [name, c] of Object.entries(ElementPlusIcons)) app.component(name, c)`。
4. **MyBatis 分页取值**：`PageQuery` 原本只有 `offset()`/`limit()` 方法，XML 的 `#{offset}` 取不到值 → 已补 `getOffset()`/`getLimit()`。
5. **权限码缺失会让功能必然不可用**：原 25 条只有 list/update，缺 create/delete，`@RequirePermission("xxx:create")` 必然被拒。补丁脚本 `docs/sql/patch-phase2-permission.sql` 已补至 44 条（INSERT IGNORE 幂等，已验证可重复执行）。
