- 五个真实踩坑已修复（务必记住）：① JDBC URL 的 `characterEncoding=utf8mb4` 会让 MySQL Connector/J 抛 UnsupportedEncodingException，必须写 `UTF-8`；② Druid `initial-size` 需设 0（懒加载）+ `fail-fast`，否则 DB 不可用时应用起不来；③ Druid `max-wait` 调 5s，否则健康检查阻塞；④ lz-common 要加 `jakarta.validation-api`（provided）；⑤ **Agent 会话环境注入了 `SERVER__PORT=56043`，Spring 宽松绑定会覆盖 server.port**，本地验证需显式 `--server.port=8088`；curl 需加 `--noproxy '*'`（环境有 HTTP_PROXY）。
- 验证结果：`mvn -B -DskipTests package` BUILD SUCCESS；`java -jar lz-app.jar` 启动 OK，`/api/system/health` 真实返回 `database.connected=false`（无口令）、6 项外部依赖如实显示未启用；`/swagger-ui/index.html`、`/v3/api-docs` 均 200；`npm run build` 成功（8.06s）。
