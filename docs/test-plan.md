## 1. 测试分层

| 层级 | 范围 | 工具 | 是否依赖外部服务 |
|---|---|---|---|
| 单元测试 | 工具类、签名器、校验器、状态机、切分器、检索评分 | JUnit5 + Mockito | 否 |
| 集成测试（Mapper） | SQL 正确性、唯一约束、聚合统计 | `@SpringBootTest` + `@Transactional` | MySQL |
| 接口测试 | Controller 全链路含鉴权 | `@SpringBootTest` + MockMvc / HTTP 脚本 | MySQL |
| 端到端 | 管理员发码 → H5 打卡 → 记录落库 → 统计刷新 | 手工脚本 + 前端实操 | MySQL + 浏览器 |
