# 原始资料存档（只读）

本目录存放实训项目下发/整理的**原始文档**，为需求溯源与答辩对照的唯一依据。

> 约定：本目录下的文件为**只读存档**，任何情况下不修改。需求有歧义时，以本目录原始文档为准。

## 文件清单

| 文件 | 角色 | 说明 |
|---|---|---|
| `北游JavaEE工程实践(4周).docx` | **首要依据** | 学校下发的《北游 JavaEE 工程实践》4 周实训方案。含项目介绍、核心功能、20 天课程计划、技术选型、考核评估标准，正文内嵌 9 张图片（架构图、后台截图、人脸比对界面、AI 助手示例等）。 |
| `项目分析.docx` | 分析材料 | 对上述原始方案的逐条拆解，区分"明确要求 / 分析判断 / 待确认"。**注意：其中的判断属于辅助分析，不等同于校方要求。** |
| `项目总指令.docx` | 执行纲领 | 对项目实施过程的总体指令：角色定义、0–8 阶段划分、阶段汇报要求、文档规范、诚实性原则。 |

## 三者的优先顺序

```
北游JavaEE工程实践(4周).docx   （校方要求，最高）
        ↓
项目总指令.docx                （执行方式要求）
        ↓
项目分析.docx                  （辅助理解，不可作为需求来源）
```
